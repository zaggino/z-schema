# AGENTS.md — z-schema

JSON Schema validator library (draft-04, draft-06) written in TypeScript. Runs in Node.js and browsers.

## Quick Reference

| Action              | Command                                                              |
| ------------------- | -------------------------------------------------------------------- |
| Install             | `npm install`                                                        |
| Build               | `npm run build`                                                      |
| Test (all)          | `npm test`                                                           |
| Test (node only)    | `npm run test:node`                                                  |
| Test (browser only) | `npm run test:browser`                                               |
| Test (single)       | `npx vitest run --silent=false --project node -t "draft4/type.json"` |
| Lint                | `npm run lint`                                                       |
| Lint (check)        | `npm run lint:check`                                                 |
| Format              | `npm run format`                                                     |
| Format (check)      | `npm run format:check`                                               |
| Type-check tests    | `npm run build:tests`                                                |

## Project Structure

```
src/                  # Library source (TypeScript, ESM)
  index.ts            # Public API — all exports go through here
  z-schema.ts         # ZSchema class variants (sync/async/safe)
  z-schema-base.ts    # Core validation logic shared by all variants
  z-schema-options.ts # Options interface and defaults
  z-schema-reader.ts  # Remote schema reader
  schema-compiler.ts  # Schema compilation ($ref resolution, id collection)
  schema-validator.ts # Schema-level validation
  json-validation.ts  # JSON instance validation against compiled schemas
  schema-cache.ts     # Schema caching by URI/id
  errors.ts           # Error codes and ValidateError class
  format-validators.ts# Built-in & custom format validators
  report.ts           # Validation report (error accumulation)
  json-schema.ts      # TypeScript types for JSON Schema (draft-04, draft-06)
  utils/              # Pure utility functions (clone, json, uri, etc.)
  schemas/            # Bundled JSON Schema meta-schemas (generated by build)
test/
  spec/               # Test files (*.spec.ts, *.node-spec.ts, *.browser-spec.ts)
  fixtures/           # Test fixture data
  lib/                # Test helpers
  public/             # Browser test assets
json-schema-spec/     # Git submodule — official JSON Schema specifications
scripts/              # Build scripts (copy-schemas.mts)
```
