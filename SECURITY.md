# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 12.x    | Yes       |
| Older   | No        |

Only the latest major version receives fixes.

## Reporting a vulnerability

Report a suspected vulnerability privately through GitHub's
[Report a vulnerability](https://github.com/zaggino/z-schema/security/advisories/new) form.
Do not open a public issue for a suspected vulnerability.

Please include:

- the z-schema version and Node.js or browser version
- a minimal schema and data that show the problem
- what happened
- what you expected to happen

You will receive an acknowledgement. When a fix is warranted, it is released as a patch version, together with an
advisory.

For guidance on validating input from sources you do not control, see [docs/security.md](docs/security.md).
